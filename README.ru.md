# ClickHarbor

[English](README.md) · **Русский**

ClickHarbor — нативное приложение для настройки мышей IO Airox и Aurora на macOS. Выбранные параметры сохраняются в памяти мыши.

## Скачать

[Скачать последнюю версию](https://github.com/Skrever/clickharbor/releases/latest)

Требуется **macOS 14 Sonoma или новее**. Универсальная сборка подходит для Mac с чипами Apple и процессорами Intel.

1. Скачайте универсальный ZIP-архив из файлов релиза. Для версии 2.0.0 он называется `ClickHarbor-2.0.0-macOS-universal.zip`.
2. Распакуйте архив и переместите `ClickHarbor.app` в **Программы**.
3. Откройте ClickHarbor и подключите мышь одним из способов, указанных ниже.

Сборка подписана ad hoc и распространяется без нотариального заверения Apple. При первом запуске macOS может показать предупреждение о проверке приложения. [Инструкция Apple для первого запуска](https://support.apple.com/ru-ru/102445)

## Поддерживаемые мыши

| Модель | Подключение |
| --- | --- |
| IO Airox | USB-кабель с передачей данных |
| IO Aurora | USB-кабель с передачей данных или комплектный приёмник 2,4 ГГц |

Когда ClickHarbor обнаруживает неподдерживаемую внешнюю мышь, он показывает сообщение. Если Aurora уснула, подвигайте мышь или нажмите кнопку, чтобы приложение восстановило связь.

## Настройки

- Меняйте значения ступеней DPI и выбирайте активную ступень.
- Устанавливайте частоту опроса 125, 250, 500 или 1000 Гц.
- Регулируйте дебаунс кнопок.
- Переназначайте шесть кнопок. Среди действий для музыки есть воспроизведение и пауза, следующий и предыдущий трек.

Нажмите **Считать**, чтобы получить текущие значения с мыши, и **Применить**, чтобы записать изменения. После записи ClickHarbor повторно считывает настройки для проверки.

Интерфейс следует системной светлой или тёмной теме и учитывает настройку macOS «Уменьшение движения».

## Сборка из исходников

Для сборки из исходников нужна macOS 15 или новее и Xcode Command Line Tools со Swift 6.

```sh
./build.sh
```

Готовое приложение появится в `build/ClickHarbor.app`. Команда `./release.sh` создаёт универсальный ZIP-архив и файл с контрольной суммой SHA-256 в папке `build/`.
