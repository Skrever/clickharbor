# ClickHarbor

[English](README.md) · **Русский**

ClickHarbor — нативное приложение для настройки мышей IO Airox и Aurora на macOS. Выбранные параметры сохраняются в памяти мыши.

## Скачать

[Скачать последнюю версию](https://github.com/Skrever/clickharbor/releases/latest)

Требуется **macOS 14 Sonoma или новее**. Универсальная сборка подходит для Mac с чипами Apple и процессорами Intel.

1. Скачайте из файлов релиза образ с окончанием `-macOS-universal.dmg` и откройте его.
2. Перетащите **ClickHarbor** в папку **Программы** в окне образа. Если вы скачали ZIP, распакуйте его и переместите `ClickHarbor.app` в **Программы**.
3. Откройте ClickHarbor и подключите мышь одним из способов, указанных ниже.

Сборка подписана ad hoc и распространяется без нотариального заверения Apple. При первом запуске macOS может показать предупреждение о проверке приложения. [Инструкция Apple для первого запуска](https://support.apple.com/ru-ru/102445)

## Поддерживаемые мыши

| Модель | Подключение |
| --- | --- |
| IO Airox | USB-кабель с передачей данных |
| IO Aurora | USB-кабель с передачей данных или комплектный приёмник 2,4 ГГц |

Когда ClickHarbor обнаруживает неподдерживаемую внешнюю мышь, он показывает сообщение. Если Aurora уснула, подвигайте мышь или нажмите кнопку, чтобы приложение восстановило связь.

## Настройки

- Выбирайте число ступеней DPI и активную ступень. Настраивайте DPI для обеих осей вместе или отдельно по X и Y.
- Выбирайте цвет каждой ступени. У Aurora есть постоянный свет, пульсация, яркость и скорость пульсации индикатора DPI.
- Устанавливайте частоту опроса 125, 250, 500 или 1000 Гц.
- Регулируйте дебаунс, высоту отрыва, выпрямление траектории, подавление дрожания и таймер сна. Дополнительные параметры сенсора и питания зависят от модели.
- Назначайте на шесть кнопок действия мыши, клавиши, сочетания и управление музыкой. Записывайте и редактируйте макросы, задавайте повторы и переносите их в формате JSON.
- Сохраняйте именованные профили на Mac. Если прошивка Aurora предоставляет встроенные профили, их можно переключать из приложения.
- Смотрите уровень заряда и версию прошивки. Для распознанных устройств доступны сопряжение приёмника Aurora и заводской сброс Aurora.

Нажмите **Считать**, чтобы получить текущие значения с мыши, и **Применить**, чтобы записать изменения. После записи ClickHarbor повторно считывает настройки для проверки.

Интерфейс следует системной светлой или тёмной теме и учитывает настройку macOS «Уменьшение движения».

Цвет ступени меняет индикатор DPI. Оригинальные программы для этих моделей не предоставляют отдельной настройки RGB корпуса. Обновление прошивки, заводской сброс Airox и её беспроводной приёмник пока не поддерживаются. Airox позволяет установить новый макрос и определить, какая кнопка уже запускает макрос. Считывание последовательности из памяти Airox недоступно.

## Сборка из исходников

Для сборки из исходников нужна macOS 15 или новее и Xcode Command Line Tools со Swift 6.

```sh
./build.sh
```

Готовое приложение появится в `build/ClickHarbor.app`. Команда `./release.sh` создаёт универсальные DMG и ZIP с контрольными суммами SHA-256 в папке `build/`.
